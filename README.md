### Public web data into spreadsheets and AI agents

I maintain two free, MIT-licensed collections: the files behind the [Scraper Finder](https://www.youtube.com/@ScraperFinder) YouTube Shorts. Each Short shows one data job; the matching files are here.

- **[scraping-n8n-workflows](https://github.com/bolvein-firex/scraping-n8n-workflows)**: importable n8n workflows that collect public data (Google Maps leads with emails, Amazon and Shopify prices, Zillow listings, Indeed jobs, TikTok, Reddit, Google Trends), clean and dedupe the rows, and append them to Google Sheets.
- **[scraping-skills](https://github.com/bolvein-firex/scraping-skills)**: the same jobs as agent skills (SKILL.md) for Claude Code and other agents, each with its real input and output fields and a runnable example.

Both run public Apify Actors on your own Apify account, work with public data only, and keep the first run small. Missing a site? Open a request in either repo.
